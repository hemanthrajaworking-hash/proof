Ledger vs statement matching (exceptions only)

Matches your books line by line against an outside statement and lists every line that does not match, with a reason. Built first for Indian GST purchase records; the same matching method fits marketplace payout vs order checks.

What it does

  • Matches in passes: exact, then cleaned-up invoice numbers, then the same invoice under a different ID.
  • Small rounding tolerance (adjustable).
  • Gives every line a status (for example value mismatch, missing in statement, missing in books) and a plain-English next step.
  • Exports an Excel workbook and an HTML exceptions report.
