Month-end budget vs actual pack

Budget vs actual by line, with only the variances that matter flagged and explained.

What it does

  • Knows that under-spending on a cost line is good news, not bad.
  • Flags a variance only when both the % and the amount are big enough (both adjustable).
  • Writes a one-line comment for each material variance.
  • Adds a simple 3-month trend forecast per line.
  • Output: a 4-sheet Excel pack and an HTML dashboard.
